用户支持

遇到定位、后台守锚或告警问题时，可以先完成以下检查。

安全提示： 定海是辅助守锚工具，不能替代人工值守、合规船载设备或独立警报措施。

无法部署锚点

  1. 打开系统“设置”→“隐私与安全性”→“定位服务”→“定海”。
  2. 将位置权限设为“始终”，并开启“精确位置”。
  3. 回到开阔位置，等待 App 显示可靠船位后再部署锚点。

后台没有收到提醒

  1. 确认定海仍在守锚，且没有执行“起锚并结束”。
  2. 在系统“设置”→“通知”→“定海”中允许通知和声音。
  3. 检查系统音量、专注模式及连接的蓝牙音频设备。
  4. 不要从最近使用的 App 中强制划掉正在守锚的定海。

定位状态长时间不可用

GPS 在舱内、金属遮挡密集区域或卫星视野不足时可能延迟。请移动到更开阔的位置，并确认系统定位服务已开启。 在获得可靠位置前，不要把 App 作为唯一守锚依据。

联系开发团队

如果问题仍然存在，请在 GitHub Issues 提交反馈，并注明设备型号、iOS 版本、复现步骤和你看到的状态。

请勿公开提交真实船位、移动轨迹、Apple 账户信息或其他敏感内容。
